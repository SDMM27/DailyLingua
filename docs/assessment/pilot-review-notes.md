# Bilan par compétence : notes pour les relecteurs du pilote

Les 12 dossiers de `src/lib/assessment/dossiers/` (russe et italien, A1 à C2) sont des brouillons écrits par un modèle. Aucun n'a été relu par un natif. Le relecteur vérifie tout le texte ; les passages ci-dessous sont ceux dont les rédacteurs doutaient.

Après relecture : renseigner `reviewedOn`, puis lancer `npm run assessment:check`. Plusieurs dossiers sont près des limites de longueur (ru-c1-1, ru-c2-1, ru-b2-1, ru-a2-1 pour le script).

## Russe

- **A1** : « Нам хорошо дома ». Le script (samedi au café) est peu lié au texte (dimanche chez la grand-mère) : à rapprocher si possible.
- **A2** : « я очень ждала эту поездку » ; « теплоход » ; « в Казани бывает холодно даже летом » (fait discutable).
- **B1** : « спальных районов » ; « выделить краску и инструменты » ; « Жители, впрочем, не хотят зависеть от чужих решений » ; « Если бы она тогда, когда проект только начинался, промолчала » (lourdeur).
- **B2** : « далёкого от науки » ; « погоня за сенсациями » ; « нежели скромные подтверждения » ; « грантополучателей » ; « перестраиваются быстрее » ; « Согласитесь, это совсем другая атмосфера ».
- **C1** : « ибо » ; « отстоит от действительности » ; « полагал свои умолчания добродетелью » ; « молчание источника — такое же свидетельство » ; « уездного города » avec « наместником » et une « летопись » (anachronisme possible). « вспыхивали волнения » remplace une première version fautive.
- **C2** : « порода книг » ; « раздаётся щедро » ; « хулить — себе дороже » ; « юбилейного красноречия » ; « не удосужившихся » ; « соавтором куда более снисходительным » ; le registre ironique d'ensemble.

## Italien

- **A1** : « a dieci minuti a piedi » ; le naturel du dialogue du script.
- **A2** : « Io ho preso le tagliatelle al ragù, la mia amica Sara ha scelto… » ; « delle tagliatelle fresche per la nonna » ; « sentire il profumo ».
- **B1** : « l'assessora alla cultura » ; « riaprirà le porte al pubblico » ; « cinema d'essai » ; le congiuntivo imperfetto « si sistemassero » (haut pour B1 ?).
- **B2** : « respirano finalmente un po' meglio » ; « il garante locale per la riservatezza » ; « risalire alle singole persone » ; « ricucire la fiducia » ; « a detta dei tecnici » ; la concordance de « Perché la fiducia non si perda, sarebbe necessario che… fossero coinvolti ».
- **C1** : « illusione monetaria » ; « ciò che si lascia contare » ; « Quanto più… tanto più… » ; le passato remoto du script ; « di scorciatoia si tratta ».
- **C2** : les ironies (« il tribunale permanente delle opinioni ») ; « il silenzio… è uno dei rumori più eloquenti » ; « demiurgo » ; la fluidité de la longue phrase d'ouverture.
