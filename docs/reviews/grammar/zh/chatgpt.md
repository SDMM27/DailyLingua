- [important] `rule[0]` — Actuel « Le verbe 是 (shì) correspond à « être » devant un nom : 我是老师 (wǒ shì lǎoshī, je suis professeur). - [bloquant] `rule[1]` — Actuel « Devant un adjectif, on n’emploie pas 是 : l’adjectif est lui-même le prédicat, et on le fait précéder de 很 (hěn) : 她很高 (tā hěn gāo, elle est grande). Le ton neutre est fréquent avec les particules et certains compléments directionnels en parole suivie. Les transformations bornent l’ordre des mots, les particules demandées et, quand elle compte dans la comparaison de l’application, la virgule interne.
