# Relecture des banques du test de niveau

Le test de niveau utilise 19 banques de 60 questions. Chaque banque couvre la grammaire, le vocabulaire et la compréhension écrite de A1 à C2.

## Méthode

1. Deux agents relisent les questions séparément. Ils évaluent les quatre choix dans leur contexte, vérifient la réponse attendue et jugent si la difficulté correspond au niveau visé. Pour la compréhension écrite, ils cherchent l'indice dans le passage et vérifient que les autres réponses en sont exclues.
2. L'arbitrage rapproche les observations par identifiant, retient les corrections justifiées et vérifie le résultat. Les rapports `pass-a.md`, `pass-b.md` et `decision.md` retracent ce travail pour chaque langue.
3. Le contrôle du projet vérifie les identifiants, les trous, la répartition des compétences et l'équilibre des positions des bonnes réponses. La comparaison avec la version précédente permet de vérifier que les identifiants, les compétences, les niveaux et les indices des réponses sont conservés. Le serveur utilise ces données pour vérifier les réponses aux tests déjà commencés.

La grille `x0-placement-2026-11-10` identifie la relecture éditoriale par IA. La difficulté reste une estimation éditoriale. Pour mesurer la difficulté réelle, il faudra observer les réponses d'apprenants dont le niveau est connu indépendamment du test.
